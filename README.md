# Fase de extracción de datos
## Srcapeando OCC
El **explorador.py**: se usa el explorador para poder hacer un mapa de ruta para el **scrapper_OCC.py**, hay que configurar varios parámetros 
para busquedas personalizadas en el scrapper explorador, tales como:
- CONFIG: Permite delimitar los estados en los que se buscara la vacante
- URL_BASE: Es necesario ajustarla a la url de la vacante base para la generación dinamica de las URLs de los demas estados
- timeout: ajustado a 10000 ms , preferentemente no modificar para evitar bloqueos
